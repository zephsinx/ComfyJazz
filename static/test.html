Testing Checklist

  • ✅ Background music plays automatically

  • ✅ Press 'c' to open the control panel
  • ✅ Volume control works
  • ✅ Settings are saved between refreshes

Next Steps

After confirming that the static version works:

  1. Upload the static folder contents to your web server
  2. Add as a browser source in OBS using the URL to your hosted version
  3. Add your Twitch channel as a parameter: ?channel=yourname
  4. For YouTube, add Streamer.bot integration: &useStreamerBot=true
